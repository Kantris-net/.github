# Contributing to Our Projects

First off, thank you for taking the time to contribute! 🎉

## How Can I Contribute?

- **Reporting Bugs:** Create an issue using the Bug Report template and provide steps to reproduce.
- **Suggesting Features:** Open a feature request to discuss new ideas.
- **Pull Requests:**
  1. Fork the repo and create your branch from `main` (e.g., `feature/my-feature` or `fix/issue-name`).
  2. Ensure your code builds successfully with `./gradlew build`.
  3. Reference any related issues in your commit messages (e.g., `fix: resolve whatever bug (fixes #1)`).
  4. Submit a Pull Request.
