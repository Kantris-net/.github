# Security Policy

## Supported Versions

We currently only support the latest version of our plugins and server components running on Java 25.

## Reporting a Vulnerability

If you discover a security vulnerability within any of our projects or plugins, please **do not** report it through a public GitHub issue.

Instead, please report it privately:

- **Email:** security@kantris.net
- **Discord:** Contact a server administrator directly. [Here](https://discord.gg/a4xfACzVdx)

We will review all security reports promptly and work with you to coordinate a fix before any public disclosure.
